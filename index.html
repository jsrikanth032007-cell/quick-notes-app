How It Works Behind The Scenes

1
Page Load: Calls fetchNotes() which sends a GET /api/notes HTTP request to the Express backend.
2
Add Note: Submitting sends a POST /api/notes with a JSON body {"text": "..."}.
3
Live Response: Express updates its array and responds with the new list, which JavaScript renders instantly in the DOM.

Backend API listening at http://localhost:5000/api/notes
